# Olist E-Commerce Analytics & Machine Learning

End-to-end data analytics and machine learning project using the
Brazilian E-Commerce Public Dataset by Olist.

## Project Goal

Build a reproducible analytics platform from raw e-commerce data,
covering:

- PostgreSQL
- SQL
- Data modeling
- Data warehousing
- Python
- Exploratory data analysis
- Power BI
- Machine learning

## Project Architecture

Raw Data
→ PostgreSQL
→ SQL Analysis
→ Data Warehouse
→ Power BI / Python
→ Machine Learning
